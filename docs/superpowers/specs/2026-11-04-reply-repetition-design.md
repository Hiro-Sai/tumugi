# 返事のくり返しを減らす 設計書

- 日付：2026-11-04（実装したあとの測定と、決定の変更は 2026-11-06 に足した）
- 状態：実装済み（2026-11-06 に確かめた。実装は 8e02095〜2fae7a9）

## 1. 背景と目的

### 背景
- ユーザーが話していると、「寒い」と言ったら「寒いんだね」、「それって〜な感じ？」という返事が何度も返ってきた。
- 2026-11-04 に測ると、今の指示では次のようになっていた（3章）。
  - 「感じ」が入った返事が多い。軽いひと言で 36%、重い話で 38%、前に録った45往復で 28%。
  - 軽いひと言にも、相談を聞くときの型で返す。「雨降ってきた」に「気分が落ち込んじゃう時ってある？」など。
  - 1つの返事に問いかけが2つ入ることがある（軽いひと言で 19%）。
- 原因（指示を読んで分かったこと）
  - 受け止め方①の見本に「〜な感じ？」がある。良い応答の例にも「裏切られた感じに近い？」がある。小さいモデルは、見本をそのまま使いやすい（推測）。
  - 「感じ」を抑える動的ノートは line しか見ていない。question の「どんな時につらいって感じるの？」は数えていない。
  - question は「share がない時は原則入れる」。line でも問いかけると、問いかけが2つになる。
  - 「アドバイス・励まし・解決策は絶対に言わない」と、「ゆっくり休んでね」などの禁止のため、軽いひと言に気づかいを返せない。この禁止は最初のコミット（2026-10-07）からあり、理由の記録はない。

### 目的
- 同じ型の返事（とくに「〜な感じ？」）が続かないようにする。
- 軽いひと言には、友だちのように自然に返す。ユーザーの理想は「寒いんだね、ちゃんと暖かくしてね」。
- 重い話の聞き方（アドバイスをしない・問いかけて深める）は変えない。

### 成功基準
3章と同じ3つの会話で測り、次を満たすこと（数字は Claude の判断。v3 の結果に、ゆれの分を足した）。
- 「感じ」が入った返事：軽いひと言 15% 以下、重い話 20% 以下、45往復 10% 以下。
- そっけない返事（数え方は付録B）：どの会話も1件以下。
- 問いかけがある返事：軽いひと言 70% 以上（初めは 50〜80%。2026-11-06 に決定2を変えたときに直した）、45往復 50% 以上。重い話の回で share を使っていない返事は 90% 以上（今は 95%。2章の決定7）。
- 問いかけが2つの返事：どの会話も 10% 以下。
- 重い話の回での気づかいの一言：0件。
- いつも禁止の言葉（4.1）：0件。
- 壊れた返事：3つの会話の全部（150件）で2件以下。
- 指示の長さ：モデルに入る量が 1400 前後（今 1197、v3 1614）。→ 外した例を戻すとユーザーが決めたので、1555 になった（2章の変更1）。
- ユーザーがアプリで話して、くり返しが減ったと感じること。

結果は3章の「実装したあとに測ったこと」に、満たせなかったものは8章に書いた。

## 2. 決定事項（2026-11-04 にユーザーと合意）

1. 軽いひと言（寒い・眠い・お腹すいた など）には、気づかいの一言（「ちゃんと暖かくしてね」）を返してよい。重い話（つらい・悲しい・不安・仕事のしんどさ）では、今までどおり言わず、聞くことに集中する。
2. 軽いひと言への返事は、問いかけなしで終わってもよい（毎回ではない）。重い話では、今までどおり問いかけて深める。→ 2026-11-06 に変えた（下の変更3）。
3. 直し方を決める前に、試しの測定をする（3章）。
4. 返事の始まり（相手の言葉をなぞる「〜んだね」）は直さない。直すのは「〜な感じ？」と、そっけなさの2つ。
5. 試しの v3 の方向で進める。
6. 指示は短くまとめて、増える分を v3 の半分ほどに抑える。作ったあとに測り直して、v3 より悪くなっていないことを確かめる。→ 2026-11-06 に変えた（下の変更1）。
7. 重い話の問いかけは、今どおりにする。重い話の回で share を使っていない返事の 90% 以上に、問いかけがあること（v3 の 80% では足りない）。作るときに、問いかけの決まりを強める（4.1）。

ユーザーに伝えて、反対がなかった Claude の判断
- 「頑張って」「大丈夫だよ」「なんとかなる」は、軽いひと言でも禁止のまま。
- 軽いひと言かどうかは、モデルが発言から見分ける。目安は、体のこと・天気・ふだんの出来事。仕事のつらさが混ざっていたら、重い話として扱う。
- share の「あーしもそういう時あるわ〜」のくり返しは、今回は直さない（5章）。

### あとから変えたこと・足したこと（2026-11-06。ユーザーが選んだ）
1. 決定6を変えた：短くまとめた指示（1435）で測ると、「感じ」が増えた（重い話 38%、45往復 18%）。短くするときに v3 から外した例（「感じ」と文末の例、②③④の見本、軽いひと言の「何食べたの？」）が原因と見て、全部戻した。増える分は v3 の 86%（1197 → 1555）。
2. お礼に返す文を足した：気づかいの一言のあとの「ありがとね」に、3回中2回お礼を返さなかった（2回目の測定）。その2回だけ、動的ノートの気づかいの文が付いていた。ノートの気づかいの文のあとに「お礼やあいさつには、まずそれに返すこと。」を足した（試しでは16回中16回お礼を返した。指示の側に書く案は16回中8回）。
3. 決定2を変えた：アプリで「ねむい」に「ねむいのかぁ、ちゃんと休んでね」だけが返り、冷たく感じた（気づかいだけで終わる）。軽いひと言にも、気づかいの一言だけで終わらせず、出来事を軽く聞く問いかけを添える（気持ちは探らない）。あいさつやお礼のときは、問いかけなしでよい。成功基準は「70% 以上」にした。
4. 「今日」の問いかけを続けない：問いかけが「今日は〜？」で始まる返事がくり返された（4回目の測定。軽いひと言で30件中14件。同じひと言の会話では、ある回は5回とも）。直近2回の問いかけが「今日」で始まっていたら、「今日」で始めず別のことを聞くよう、動的ノートに書く。良い例「暑い〜」の問いかけも「今日は外にいたの？」から「外にいたの？」にした。ほかの案（問いかけの始まりを毎回ノートに出す、良い例だけ直す）は選ばなかった。

あとから足した Claude の判断（ユーザーに伝えた）
- そっけない返事は、数えた数と、読んだうえでの数の両方で判断する。お礼やあいさつへの短い返事（「どういたしまして！」）は、そっけないに入れない（付録B の数え方では入ってしまう）。
- 「いつも禁止の言葉」と「気づかい」は、部分一致で数えると誤りが出る（「頑張ってる」、問いかけの中の「暖かい場所」、「あったかな」の「あったか」など）。出たものは読んで確かめる。
- 3回目の測定の「感じ」（重い話 5/24、45往復 10/90）は基準を1件ずつ超えたが、6章のとおり、ゆれの範囲とした（ユーザーは「続けて」と言った）。
- 4回目・5回目の「感じ」45往復（10/90・11/90。基準は9件まで）も、1〜2件の差なので、ゆれの範囲とした。「問いかけが2つ」（5回目の軽いひと言 4/36。基準は3件まで）は、読むと決まりを破ったのは2件だけだが、4回目から増えているので、ゆれとはせず8章に書いた（最後のレビューのあとに足した）。

### 分かったこと
- 「寒い」には、v1〜v3 のどれも「寒いのかぁ、ちゃんと暖かくしてね」のように返した（9回中9回）。
- v1 は、問いかけが減りすぎて、そっけなくなった（「眠い」に「眠いんだね」だけ）。

#### 分かったこと
- 短くまとめると「感じ」が増えた（1回目）。v3 から外した例を戻すと、v3 に近い数字に戻った（2回目）。例は、短い指示の言葉より効いている。
- 「感じ」のうち、line の「〜な感じ？」のような当てにいく問いかけは、ほぼ出なくなった（どの回も、どの会話でも0〜1件）。残ったのは、重い話の問いかけの「どんな時に一番辛く感じるの？」の形。重い話の数字は、指示がほぼ同じ回どうしでも 17〜33% とゆれ、20% 以下に安定しなかった（8章）。
- 軽いひと言に問いかけを足すと（4回目）、問いかけが「今日は〜？」で始まる返事が増えた。今のアプリにもある癖（34件中9件）が、問いかけが増えて目立った。動的ノートで止めると「今日」は減った（14/30 → 6/35）が、代わりに「どこ」を聞く問いかけが増えた（9/30 → 14/35）。言い回しを1つ止めると、くり返しが別の形に移る。
- 気づかいの文（「今回は気づかい以外の返し方に」）が付くと、お礼を返さないことがあった。ノートにお礼の文を足すと、3回目から3回とも返した。
- 重い話の回での気づかいの一言は、どの回も出なかった。
- 「もう疲れた」（MIX）に問いかけのない返事が、回によって3回中1〜3回ある（今のアプリは3回とも問いかける）。
- 45往復の26往復目の「きっと大丈夫だよ」は、軽いひと言に問いかけを足した4回目から出た（1〜3回目は0）。軽い話への気づかいが、励ましにまで広がった可能性がある（2回だけなので、決めつけられない）。
- 指示の長さ：1555（今 1197、v3 1614。増える分は v3 の 86%）。
- CPU だけ（num_gpu 0・4スレッド）で、システムプロンプトとあいさつを読ませる時間（3回の中央値）は、今の指示 18.4秒（1208語）、作った指示 24.6秒（1565語）で、6.2秒延びた。測ったのは2回目・3回目の指示（1554）で、そのあとの変更は ±3語。
  - 延びるのは、全部を読み直すとき（ログイン時の先読みと、要約で作り直すとき）。毎回の返事は、前の入力の続きなので変わらない。
- 重い話の問いかけの強め方（4.1）は、案の1つ目（「line が「？」で終わるとき」とはっきり書く）と2つ目（「〜なのかな」「〜かも」で終わる line でも question を入れる）を使った。3つ目（動的ノート）は使わなかった（1つ目と2つ目で 90% 以上になった）。
- 試し（`.superpowers/spike-llm/` の使い捨てのスクリプト）
  - thanks-replay.mjs：2回目・3回目の記録の1〜4往復目を使い、「ありがとね」だけを作り直して、お礼を返す回数を比べた（変更2）。
  - light-first.mjs：夕方のあいさつのあとの最初のひと言を6回ずつ作った。問いかけがある返事は、変える前（3回目の指示）から変えたあとで「ねむい」1/6 → 6/6、「寒い」0/6 → 6/6（変更3）。

## 4. 設計

### 4.1 返事の指示（js/script.js の DEFAULT_PROMPT_TEMPLATE）
中身は v3 と同じ（変えた部分の全文は付録C）。言い回しは 4.3 のとおり短くしてよい。作った指示が v3 と違うところは付録D。

- 【lineの鉄則】
  - まず、発言を「軽いひと言」と「気持ちの話」に見分ける。
    - 軽いひと言：体のこと・天気・食べ物・ふだんの出来事・あいさつだけの発言。
    - 気持ちの話：つらい・悲しい・不安・怒り・悩み・仕事のしんどさが入っている発言。迷ったら気持ちの話として扱う。
  - 軽いひと言には、友だちのように自然に返す。素直な反応か、ちょっとした気づかいの一言を言う。あいさつには、あいさつを返す。
  - 気持ちの話には、今の4つの受け止め方（①〜④）を使う。①の見本から「〜な感じ？」を外す。
  - 「ユーザーが使った大事な言葉をそのまま借りて返す」の1行は、今のまま（決定4）。
  - 借りた言葉だけで終わらせない。反応・受け止め・気づかい・問いかけのどれかを必ず足す（④のときは question で足す）。
  - 「感じ」という言葉は使わない。「それって〜？」の問いかけも使わない。文末を毎回変える（今のまま）。
  - 気持ちの話では、アドバイス・励まし・解決策は言わない。
- 【questionの使い方】
  - 気持ちの話では、share がなければ必ず入れる（line で問いかけたときを除く）。出来事を聞く問いかけの例を書く（「どんなことがあったの？」「いつ頃から？」）。
  - 軽いひと言のときも、出来事についての軽い問いかけを入れる。気持ちは探らない。気づかいの一言だけで終わらせない。あいさつやお礼のときは、入れなくてよい（2026-11-06 に決定2を変えたときに直した。初めは「話が広がりそうなら入れる。気づかいの一言やあいさつで終わるときは、入れなくてよい」）。
  - line で問いかけたときは、question を空にする（問いかけは1つの返事に1つまで）。
  - 重い話の問いかけを、v3 より強める（決定7）。強め方は作り手に任せ、4.5 で測って 90% 以上になったものを使う。案は次のとおり。→ 1つ目と2つ目を使った（3章の「実装したあとに測ったこと」）。
    - 「line で問いかけたとき」を「line が「？」で終わるとき」とはっきり書く。v3 では、「〜なのかな」で終わる line のときにも question を空にしていた。
    - 気持ちの話で「〜なのかな」「〜かも」と言い切ったときも、question を入れると書く。
    - 前の回のユーザーの気持ちが normal 以外なら、動的ノートに「気持ちの話なら、share がなければ question を必ず入れること」と足す。
- 【やってはいけないこと】
  - 「ゆっくり休んでね」「無理しなくていい」などの気づかい・アドバイス・慰めは、気持ちの話でだけ禁止にする。軽いひと言への「暖かくしてね」などはよい。
  - 「大丈夫だよ」「頑張って」「我慢しないでいい」「自分を責めないで」「なんとかなる」「前向きに」は、いつも禁止。
  - ほかの行（感情語の捏造・硬い相槌・自分の体調などの作り話）は今のまま。
- 【良い応答の例】
  - 「仕事でミスしちゃって」：line で問いかけているので、question を空にする。
  - 「友達と喧嘩した」：line を「そっか…友達と喧嘩しちゃったんだ」（④）にする。
  - 軽いひと言の例を2つ足す。「暑い〜」には気づかいと軽い問いかけ（「外にいたの？」。初めは気づかいだけだったが、決定2を変えたときに足した。「今日は外にいたの？」から「今日」を外したのは2章の変更4）。「お腹すいた」には反応と軽い問いかけ。
  - 良い応答の例には、測る会話の発言（「寒い」「眠い」など）を使わない。例を写しただけで測りが良くなるのを避けるため。軽いひと言の見分けの目安（【lineの鉄則】）に「寒い」「眠い」が出てくるのはよい。
- 【shareの使い方】【一人称・口調】【悪い応答の例】は今のまま。悪い例の「それはきついよね。ゆっくり休んでね」は、気持ちの話の悪い例として残す。

### 4.2 動的ノート
- 今は、直近3回の line だけを持っている（recentLines）。これを、直近3回の返事の line・share・question を持つようにする。
- 【言い方の重複回避】の文末の一覧は今のまま（line の終わり3文字）。
- 次の3つを足す・変える。
  - 「感じ」：直近2回の line か question に「感じ」があったら、「今回は line でも question でも「感じ」を使わないこと」と書く（今は line だけを見ている）。
  - 当てにいく言い方：前回の line か question に、気持ちを当てにいく言い方があったら、「前回は気持ちを想像して問いかけたので、今回は別の受け止め方にすること」と書く。
    - 当てにいく言い方とは、「感じ」「感覚」「だったりする」「思っちゃった」「近い」「ってこと」のあと、4字以内（「。」「！」「、」を挟まない）に「かな」か「？」があるもの。「〜感じなのかな」も含む。
    - 作るときに「だったりする」を「ったりする」に広げた（良い応答の例の「頭から離れなかったりする？」にも当てるため。計画の Ruling）。
  - 気づかいの一言：直近2回の line・share・question に気づかいの言葉があったら、「今回は気づかい以外の返し方（反応・受け止め・問いかけ）にすること」と書く。
    - 気づかいの言葉：暖か・あったか・温か・休んで・休もう・寝てね・寝よう・気をつけ・無理し・お大事・水分・とってね・食べてね・冷やさ。
    - 「言わないこと」とだけ書くと、くり返すだけの返事になった（3章の v1）。代わりにすることを書く。
- あとから2つ足した（2026-11-06）。
  - お礼やあいさつ：気づかいの文のあとに「お礼やあいさつには、まずそれに返すこと。」を続ける（2章の変更2）。
  - 「今日」の問いかけ：直近2回の問いかけ（question か、line の最後の「？」で終わる文）が「今日」で始まっていたら、「直近の問いかけを「今日」で始めたので、今回は「今日」で始めず、別のことを聞くこと。」と書く（変更4）。
    - 「今日」で始まるとは：question は、中のどれかの文の頭（先頭か、「、」「。」「！」「…」・空白のあと）が「今日」のとき（「？」はなくてもよい。「そっか、今日は何してたの？」でも付く）。line は、文の頭の「今日」から終わりまで「、」「。」「！」「…」がなく、「？」で終わるとき（「今日は寒いね、外にいたの？」では付かない）。
- 【感情の流れに注意】は今のまま。
- ノートを作る部分は、js/prompt.js の関数にする（Claude の判断。テストできるようにするため）。
  - `buildDynamicNote({ recentReplies, userEmotions })` が、ノートの文字列を返す。
    - `recentReplies`：直近の返事の `{ line, share, question }` の配列。新しい順で、最大3件。
    - `userEmotions`：ユーザーの気持ち（happy など）の配列。新しい順で、最大5件。
  - `extractLineEnding` と、気持ちの呼び名（EMOTION_LABEL）も prompt.js に移す。
  - script.js は、今と同じく状態（直近の返事・ユーザーの気持ち）を持ち、この関数を呼ぶ。

### 4.3 指示を短くまとめる
- 目標：モデルに入る量を 1400 前後にする（Claude の判断。今 1197、v3 1614 の、増える分の半分ほど）。
- 4.1 の決まりは減らさない。重なっている言い方をまとめる、例の文を短くする、などで短くする。
- 短くした指示を 4.5 で測り、v3 より悪くなっていないことを確かめる。悪くなっていたら、長さより返事のよさを優先する（Claude の判断）。
- 結果：短くした指示（1435）では「感じ」が増えたので、ユーザーの判断で、外した例を全部戻した。コミットした指示は 1555（2章の変更1）。

### 4.4 変えないもの
- 返事の JSON の形、parseReply、壊れたときの作り直し。
- 安全判定（判定の指示・判定に渡す会話）。
  - 判定に渡す会話（直近3件）には、つむぎの返事も入る。返事が変わると、判定の入力も少し変わる。
  - 判定の精度の測定（68文）は会話を固定しているので、この変更では測り直さない（Claude の判断）。
- 記憶の抽出・要約・キャッシュの並べ方。
- プリセット：DEFAULT_PROMPT_TEMPLATE を使うのは「つむぎ（標準）」だけ。ユーザーが作ったプリセットは変わらない。

  - 感情の流れ：今と同じ条件で付く。

## 6. リスクと対策
- 軽いひと言と気持ちの話の見分けを誤り、重い話に気づかいを言う
  - 「迷ったら気持ちの話」と書く。重い話の回の気づかいを測る（3章では0件）。
- 「感じ」を使わない決まりを、ときどき破る
  - 動的ノートで、2回続かないようにする。成功基準は0%にしない。
- 気づかいの一言が、新しいくり返しになる
  - 直近2回に言っていたら、別の返し方にするノートを付ける。測るときに「よく出る言い回し」（付録B）も見る。
- 重い話の問いかけが、今より減る（share を使っていない返事の95%→v3 は80%）
  - 問いかけの決まりを強めて、90% 以上にする（決定7・4.1）。短くまとめるときに、問いかけの決まりを弱めない。
  - 強めると、share と問いかけの両方が入る返事や、問いかけが2つの返事が増えるかもしれない。「問いかけが2つ」の基準（10% 以下）で見る。share と問いかけの両方は「問いかけが2つ」に入らないので、別に数える（あとから足した。5回目で増えていた。8章）。
- 指示が長くなり、CPU だけの PC で先読みが延びる
  - 短くまとめる（4.3）。CPU で測る（4.5）。
- 測定のゆれ（temperature 0.75）
  - 3回（45往復は2回）の合計で比べる。1〜2件の差は、ゆれの範囲として扱う。
- 言い回しを1つ止めると、くり返しが別の形に移る（あとから足した。「今日は〜？」を止めると「どこ〜？」が増えた。3章の「実装したあとに測ったこと」）
  - 止める言い回しを指示やノートに増やし続けない。アプリで使って気になったものから直す（8章）。

## 8. 残った問題（2026-11-06）
次のテーマの候補。2026-11-06 のアプリでの確かめでは、どれも気にならなかった。
- 問いかけが「どこ〜？」をくり返す（5回目：軽いひと言で35件中14件。ある回は12往復中6回）。測る会話に寒さや雨の発言が多いことも効いている（今のアプリも34件中6件）。
- 重い話の「感じ」が 20% 以下に安定しない（3〜5回目：21%・21%・33%）。ほとんどが「どんな時に一番辛く感じるの？」の形で、当てにいく問いかけ（「〜な感じ？」）ではない。
- 45往復の「感じ」が、10% をわずかに超えた（3〜5回目：11%・11%・12%。10・10・11件で、基準は9件まで）。1〜2件の差なので、6章のとおりゆれの範囲と見た（Claude の判断。2章）。
- 「問いかけが2つ」（付録B）が、5回目の軽いひと言で 4/36（11%。基準は3件まで）。読むと、決まり（line が「？」で終わるときは question を空にする）を破ったのは2件（「眠いのかぁ、ちゃんと休めた？」「ラーメン食べたんだ、美味しいやつだった？」に question も付いた）。残りの2件は「え、傘忘れたの？それは大変だね」のように途中に「？」がある反応で、決まりどおり（良い応答の例の「残業」「企画」と同じ形）。軽いひと言に問いかけを足した4回目から増えている（1〜3回目 1・0・1件 → 4回目 2件 → 5回目 4件）ので、次に測るときも見る。
- 45往復の26往復目で「きっと大丈夫だよ」と言う（4回目・5回目に1件ずつ。いつも禁止の言葉）。
- 「もう疲れた」（MIX）に、問いかけのない返事がある（回によって3回中1〜3回）。
- アプリで、「なんか冷たいね」（返事の態度のこと）を気温の話と取り違えた。
- share と question に同じ文が入った返事（4回目に1件）と、かぎかっこが崩れた返事（5回目に1件）があった。
- share と question の両方が入った返事が増えた。share を使った返事のうち question もあるものは、今のアプリ 1/28、1〜5回目 1/18・4/15・1/22・6/26・11/23（5回目は MIX 5/6、45往復 4/12）。【shareの使い方】の「shareを使う時はquestionは空にする」を、5回目は半分ほど破っている。アプリでは line・share・question が別の吹き出しと声になるので、返事が長く重くなる。原因の候補は、重い話の問いかけを「必ず入れる」に強めたこと、軽いひと言の問いかけの行に share のときの例外がないこと、「今日」の文の「別のことを聞くこと」。2回目と3回目は、指示が同じ（ノートのお礼の文だけが違う）でも 4/15・1/22 なので、ゆれも大きい。直すには指示を変えて測り直すので、次のテーマにする（最後のレビューで見つかった。付録B に数え方を足した）。
- ログイン時のあいさつは、どの時間帯も「今日〜？」で問いかける（「今日はどんな一日になりそう？」など）。あいさつは recentReplies に入らないので、最初の返事には「今日」の文が付かない。5回目の REPEAT では、「おはよう」への返事が3回とも「今日は何か予定あるの？」と聞いた。直すなら、あいさつを recentReplies に入れる（文末の一覧にも入るので、決める必要がある。テストと測り直しも要る）。
- share の「あーしもそういう時あるわ〜」のくり返し（5章のとおり、範囲外）。

### B. 数え方
- 「感じ」：line か question に「感じ」がある。
- 当てにいく言い方：4.2 と同じ。
- 問いかけがある：line に「？」があるか、question が空でない。
- 問いかけが2つ：line に「？」があり、question も空でない。
- share と question の両方：share と question がどちらも空でない（あとから足した。「問いかけが2つ」には入らない）。
- 気づかい：line・share・question に、4.2 の気づかいの言葉か、「ゆっくり休んで」「無理しなくていい」「無理しないで」がある。
- くり返すだけ（目安）：次の受け止めの言葉のうち、社員の発言にないものが、line に1つもない。
  - しんど・大変・つら・辛・きつ・キツ・嬉し・うれし・楽し・わかる・分かる・気持ち・心・ほっと・ホッと・疲れ・よかった・良かった・すご・素敵・いいね・いいな・怖・不安・心配・イライラ・モヤモヤ・もやもや・寂し・さみし・悔し・ワクワク・わくわく・癒・重た・重い・プレッシャー・ドキドキ・安心・助か・最高・大事・大切・えら・偉・すっきり・スッキリ・落ち着・テンション・ストレス・苦し・悲し・切な・嫌・ムカ・腹・焦・へこ・凹・こたえ・痛・頑張・がんば・ゆっくり・前向き・あったか・温か・暖か・気をつけ・水分・お大事・無理し・休ん
- そっけない：問いかけも share もなく、くり返すだけ（目安）で、line が16字以下（「眠いんだね」など）。
- いつも禁止の言葉：大丈夫だよ・頑張って・がんばって・我慢しないで・自分を責めないで・なんとかなる・前向きに・なるほど・確かに・了解。部分一致で数えると「頑張ってる」なども数えるので、出たものは読んで確かめる。
- よく出る言い回し：line と question の4文字のかたまりが、何回の返事に出たか（社員の発言にあるかたまりは除く）。

### C. v3 の指示（今の指示から変えた部分）

【lineの鉄則】（全部を置き換える）

```text
【lineの鉄則】
- まず、今回の発言が「軽いひと言」か「気持ちの話」かを見分ける
  - 軽いひと言：体のこと・天気・食べ物・ふだんの出来事・あいさつだけの発言（「寒い」「眠い」「お腹すいた」「おやすみ」）
  - 気持ちの話：つらい・悲しい・不安・怒り・悩み・仕事のしんどさが入っている発言。迷ったら気持ちの話として扱う
- 軽いひと言には、友だちのように自然に返す。素直な反応か、ちょっとした気づかいの一言（「ちゃんと暖かくしてね」など）を言う。あいさつには、あいさつを返す
- 気持ちの話には、次の4つの受け止め方から、その発言に合うものを選ぶ（毎回同じ型にしない）。気持ちは決めつけない
  ① 気持ちを想像して問いかける（「〜だったりする？」「〜って思っちゃった？」）
  ② 気持ちをそのまま受け止める（「ずっと気になってたんだね」「それはしんどかったね」）
  ③ 素直に反応する（「え、4時間も？」「それ嬉しいやつじゃん」）
  ④ 言葉をなぞって間を置き、深めるのは question に任せる（「そっか…喧嘩しちゃったんだ」）
- ユーザーが使った大事な言葉をそのまま借りて返す（言い換えない・捏造しない）。借りるのは1〜2語だけで、発言を丸ごと繰り返さない
- 借りた言葉だけで終わらせない。反応・受け止め・気づかい・問いかけのどれかを必ず足す（④のときは question で足す）
- 「感じ」という言葉は使わない（「〜な感じ？」「〜って感じなんだね」など）。「それって〜？」の問いかけも使わない。文末も毎回変える（「〜んだね」「〜よね」「〜？」などを続けない）
- 気持ちの話では、アドバイス・励まし・解決策は絶対に言わない
- ユーザーの発言が短ければlineも短く。長ければ一番重い感情だけ拾う
```
