## 決めたこと

- **ユーザーが決めたこと**（2026-11-04。くわしくは設計書の2章）
  - 軽いひと言（寒い・眠い・お腹すいた など）には、気づかいの一言を返してよい。重い話では、今までどおり言わない。
  - 直し方を決める前に、試しの測定をする。試しの v3 の方向で進める。
  - 返事の始まり（相手の言葉をなぞる「〜んだね」）は直さない。
  - 重い話で share を使っていない返事の 90% 以上に、問いかけがあること。
  - 実装は、サブエージェントで進める。測定は、まとめて Claude に任せる。
- **あとから変えたこと**（2026-11-06。ユーザーが選んだ）
  - 指示を短くまとめると「感じ」が増えたので、短くするときに外した例を全部戻した（指示の長さは、今 1197 → 1555）。
  - 気づかいの一言のあとの「ありがとね」に、お礼を返さないことがあったので、ノートに「お礼やあいさつには、まずそれに返すこと。」を足した。
  - 「ねむい」に「ねむいのかぁ、ちゃんと休んでね」だけが返って冷たく感じたので、軽いひと言にも出来事を軽く聞く問いかけを添えることにした（あいさつ・お礼は除く。基準は 70% 以上）。
  - 問いかけが「今日は〜？」で続いたので、直近2回の問いかけが「今日」で始まっていたら、別のことを聞くようノートに書く。良い例の「今日は外にいたの？」も「外にいたの？」にした。
  - 最後のレビューの指摘は、記録とテストだけ直す。指示は変えない。
- **Claude の判断（ユーザーに伝えた）**
  - そっけない返事・いつも禁止の言葉・気づかいは、数えた数だけでなく、読んで確かめる（部分一致の誤りがあるため）。
  - 「感じ」が基準を1〜2件超えたもの（3回目の重い話、3〜5回目の45往復）は、ゆれの範囲とした。
  - 「問いかけが2つ」が5回目に基準を1件超えたのは、ゆれではなく増えてきているので、次に測るときに見る。
- **CPU だけの PC への影響**

## つまずいたこと

- **短くまとめた指示で、「感じ」が増えた。**
  - 短くするときに外した例（「感じ」と文末の例、受け止め方の見本、軽いひと言の例）が効いていた。小さいモデルには、短い指示の言葉より例が効く。
- **気づかいの文が付くと、お礼を返さなかった。**
  - ノートの「今回は気づかい以外の返し方に」が、お礼を返すことより強く効いた。お礼の文を足すと、3回とも返すようになった。
- **言い回しを1つ止めると、くり返しが別の形に移った。**
  - 「今日は〜？」を止めると、「今日」は 14/30 → 6/35 に減ったが、「どこ〜？」が 9/30 → 14/35 に増えた。止める言い回しをノートに増やし続けるのはやめ、アプリで気になったものから直すことにした。
- **数える道具が、同じ会話を重ねて数えていた。**
  - 測定の記録（raw.jsonl）には、同じ会話の古い記録も残る。最後の記録だけを使うように直した。
- **最後のレビューで、設計書の記録の抜けが見つかった。**
  - コミットした指示で基準を少し超えた2つ（45往復の「感じ」12%、問いかけが2つ 11%）の説明がなかった。
