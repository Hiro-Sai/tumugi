# 開発ログ セッション15（2026-11-17〜18）

## このセッションでやったこと

1. **Electron を 29 から 45 に上げた（レビューの B4）。**
   - Electron 29 は、2024年8月にサポートが終わっていた。29 にした理由の記録はなく、コードを読んだかぎり、29 に止めておく理由もなかった。
   - ほかの土台（Tauri など）に乗りかえるかも考えたが、Electron のまま行くことにした（ユーザーが決めた）。
   - 設計書を書いてから進めた（`docs/superpowers/specs/2026-11-17-electron-upgrade-design.md`）。作業は小さいので、エージェントは使わず、まとめ役が直して、ユーザーが確かめた。
2. **ユーザーが決めたこと。**
   - 上げる版は 45。
   - 使用中に外へ通信しないことを、「測る」と「ファイアウォールで止める」の両方で確かめる。
   - 次に上げ直す決まりと、確かめの手順を README に書く。
   - スマート アプリ コントロールに止められたときは、切らずに、少し前の 45 を試す（下の4）。
3. **暗号の呼び方を、非同期の形に直した。**
   - 45 では、`safeStorage` の同期の呼び方が「古い」扱いになり、46 で消える。今回いっしょに、非同期の呼び方にした。保存する形は変えていないので、29 で保存した記憶も、そのまま読めた。
   - 非同期にすると、2つの操作が途中で入りまじることがある。たとえば、パスワードの変更で記憶を付け替えている途中に、記憶の保存が前の鍵で書くと、次に読めずに記憶が消える。
   - ストアの読み書きを、すべて順番待ちに入れ、1つずつ行う形にした（`tumugi_app/task-queue.js`）。同期のときに守られていた「来た順に終わる」を、そのまま守る。
4. **出たばかりの 45.3.4 が、Windows に止められた。**
   - `npm start` が `Error: spawn UNKNOWN` で止まった。Windows の記録（CodeIntegrity）を読むと、スマート アプリ コントロールが electron.exe を止めていた。
   - Electron 本体には署名がない。署名のないアプリは、Microsoft の「評判」で判断されるので、出たばかりの版は止められた、と考えられる。29.4.6 は、出てから2年以上たっていたので動いていた。
   - 出てから2週間の 45.2.3 は動いたので、この版にした。README に、版の選び方として書いた。
   - 配るインストーラーにも署名がないので、同じように止められるおそれがある。インストーラーのテーマで扱う（レビューの一覧の E11）。
5. **通信を確かめた。**
   - 通信を測るスクリプト（`tools/net-watch.ps1`）を作り、29 と 45 で、一通り使うあいだの接続先を記録した。どちらも、つむぎ本体の接続先は PC の中の3つ（サーバー・Ollama・VOICEVOX）だけで、PC の外への接続は0件だった。
   - ファイアウォールで、electron.exe から PC の外への通信を止めた状態でも、すべての機能が動いた。
   - 規則が本当に効いているかも試した（electron.exe から example.com へ1回つなぎ、止められること）。つむぎは外へつながないので、つむぎが動くだけでは、規則が効いていなくても同じ結果になるため。
   - 実運用（サーバーが社内の別の PC にある）では、「社内は通して、インターネットだけ止める」規則になる。インストーラーのテーマで扱う。

## つまずいたこと

- `spawn UNKNOWN` は、エラーの文だけでは原因が分からなかった。Windows のイベントの記録（CodeIntegrity）を読んで、初めて分かった。
- 通信を測るスクリプトは、1秒ごとに読むつもりだったが、プロセスを数えるのに時間がかかり、約2秒ごとだった。29 と 45 は同じスクリプトで測ったので、そのまま比べた。まとめに、実際の間隔を出すように直した。

## 残る弱点（README と設計書にも書いた）

- 通信を測るスクリプトに見えるのは TCP だけで、約2秒より短い接続は見落とすことがある（そのため、ファイアウォールで止める確かめも行う）。
- 45 で保存したデータを、29 に戻して読めるかは確かめていない。
- 出たばかりの Electron は、スマート アプリ コントロールに止められることがあるので、上げるときに少し前の版を選ぶことがある。

## 学んだこと

- 同期から非同期に変えるときは、呼び方だけでなく、「途中で止まらないこと」に頼っていた所を探す。
- 「止める」確かめは、本当に止まっていることも確かめないと、何も確かめていないのと同じになる。
