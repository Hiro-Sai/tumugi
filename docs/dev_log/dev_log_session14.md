   - 作業6：説明の文と README。
   - 作業7：仕上げのレビューで見つかった点の直し（下の4）。計画のあとで足した。
4. **仕上げのレビューで、作りの穴が2つ見つかった。**
   - 作業ごとのレビューでは見つからず、全体を通したレビューで見つかった。どちらも、最初の設計の見落とし。
   - 1つ目：「登録から7日たつまで集計に入れない」を、集計のときに見ていた。待ちが明けた瞬間に、それまでの記録がまとめて集計に入る作りだった。
   - 2つ目：7日の待ちが「登録から」だけだったので、前からあるアカウントには効かなかった。
   - 直し方：社員ごとに「集計に入れ始める時刻」を持たせた。仮のパスワードを自分のパスワードに変えたとき、在籍に戻したとき、管理者の権限を外したときに、今に戻す。そこから7日の記録は、記録した時点で「集計に入れない」と決め、あとからも入れない。集計は、社員の今の状態を見なくなった。
   - 引きかえ：パスワードを忘れてリセットした人も、新しいパスワードを決めてから7日は集計に入らない。10名ちょうどの部署では、その間、集計が出ないことがある。
   - あわせて決めたこと：管理者の権限を付けた・外したときも、本人に知らせる。
5. **レビューで見つけて直したもの（主なもの）。**
   - 削除の前に記録を数える所で、同時に入った記録を見落とさない読み方にした。

   - 知らせが多いときに、「確認」のボタンが下に隠れる作りだった。一覧だけが動くようにした。
   - 同意の窓の文を、守れる約束の形にした（「次のログイン時にお知らせします。変更の履歴は「設定」で確認できます。」）。
