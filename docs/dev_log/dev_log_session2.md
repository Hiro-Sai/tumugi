## 決めたこと

- **中継の制限。** 使うエンドポイントだけを、メソッドも含めて許可する（8つ）。接続先の確認だけだと、Ollama の `/api/pull`（ネットからモデルを取得）などが通ってしまうため。
- **外部のリンク。** 開かない。クレジット画面の URL は文字で表示し、選択してコピーできるようにした。
- **フォント。** アプリに同梱する（Fontsource の npm パッケージ）。今と同じ太さだけを読み込む。
- **CSP。** スクリプトだけ厳しくした（`script-src 'self'`）。スタイルは `'unsafe-inline'` を残した（厳しくするのはバックログ）。画面側からの通信は `connect-src 'none'` ですべて禁止。
- **Ollama の cloud モデル。** 名前が `-cloud`・`:cloud` で終わるモデルへの会話は中継しない。サインインしていると ollama.com で動き、会話が PC の外に出るため。本当の守りは「Ollama にサインインしない」で、README に書いた。
- **フォントの著作権表示。** パッケージの LICENSE ではなく、フォントファイルに埋め込まれた表記を使う。

## つまずいたこと

- **ターミナルの `[net]` のログが文字化けする。**
  - 原因：アプリは UTF-8 で出力するが、PowerShell の画面が Shift_JIS で表示している。
  - 対策：`npm start` の前に `chcp 65001` を実行する。
- **展示会で Wi-Fi がなくてもフォントが変わらなかったのはなぜか。**
  - 原因：この PC には Noto Sans JP が入っていて、ほかのフォントも Electron のキャッシュに残っていた。
  - 新しい PC ではどちらもないので、同梱が必要だった。
- **Git Bash の `sed -i` が改行コードの CR を消す。** `grep -c $'\r$'` も当てにならなかった。CRLF のファイルは Edit ツールで直す。コミット時に Git が LF にそろえるので、結果には影響しない。
- **フォントのパッケージの LICENSE から、著作権表示の1行が取れない。** 複数ファイル分の表記が連結されていたり、「Google Inc.」だけだったりした。フォントファイルの name テーブルから読み出した。
- **ネットワーク上の共有（`file://ホスト名/...`）の読み込み。** Electron の webRequest で止まるかは、コードだけではわからなかった。開発者ツールで試し、CSP で止まることを確かめた。

## 残っている課題

- **ローカル完結の残り（優先度は低い）**
  - 画面の移動先を3つの画面だけに絞る（今はアプリのフォルダの中の任意の `.html`）。
  - `<link rel="dns-prefetch">` と WebRTC の守り。インストーラーで Windows ファイアウォールの送信の規則を入れる。
  - cloud モデルで拒否したとき、画面にはふつうの接続エラーしか出ない。
  - 細かい点は設計書の「8. 範囲外」にまとめた。
- **インストーラーを作る前に必須**
  - package.json の build 設定の `!**/node_modules/**` を直す。今のままでは、同梱フォントも electron-store も入らない。フォントの OFL の本文も一緒に入れる。
  - 存在しない `admin-demo.html` が build 設定に書かれている。
  - Electron の更新（29.4.6 はサポート終了済み。`npm audit` の19件もここで扱う）。
- **前回からの残り**
  - 移行の細かい改善（README のテーブル確認の手順、自動起動の説明、Minor M1〜M7）。
  - 実在の社員を DB に登録する手段がない。
  - 社内サーバーに置く前の項目（ヘッダーを隠す、バインドアドレスの変数化、TLS、ログの上限、DB ユーザーの権限、Docker Desktop のライセンス）。
  - 公開する前の項目（立ち絵の利用規約、Git の履歴の旧シードスクリプト）。
  - XAMPP の後片付け（バックアップが残っている間は Apache を起動しない）。
  - 社内 LAN 用の接続先の設定。
