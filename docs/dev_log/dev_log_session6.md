## つまずいたこと

- **立ち絵を「作者が描き足した」と誤って書き、公開したあとで気づいた。**
  - README・開発ログ・設計書の7か所に、同じ誤りがあった。ユーザーの指摘で直し、公開版にも写した。
  - 原因は、前のセッションの開発ログにあった「描き直し」という書き方を、確かめないまま引き継いだこと。
  - 人の作品に関わる書き方は、本人に確かめてから書く。
  - 公開用のリポジトリの最初のコミットには、訂正前の文が残っている。訂正が次のコミットとしてはっきり残っているので、そのままにした。
- **Xbox Game Bar の録画が大きかった。** 画面がほとんど動かなくても毎秒8.8Mbit で記録するため、2分43秒で171.6MB になった（GitHub は100MB を超えるファイルを受け付けない）。
- **`.gitattributes` のフォルダの書き方。** `docs/superpowers/plans/` のように末尾に `/` を付ける書き方は効かない。`docs/superpowers/plans` と `docs/superpowers/plans/**` の2行にした。
- **写すスクリプトの集計の誤り。** 変化の件数を数えるとき、ファイル名に入っている「D」（README の D など）まで「消した」と数えていた。最初に動かす前に、状態を表す先頭2文字だけを見るように直した。
