   - まとめ役が決めたこと：
     - .editorconfig は、改行と文字コードだけにする。.bat・.cmd は CRLF で BOM なし（BOM を付けると、1行目のコマンドが壊れる）。.ps1 は CRLF で BOM 付き（Windows の PowerShell 5.1 が日本語を正しく読むため）。

## 気づいたこと

- Git は、ファイルの大きさが記録と違うと、中身を読まずに「変わった」とみなす。改行だけを書き直したあと、`git diff` は空なのに、`git status` には変わったと出た。そのファイルを `git add` すると、記録だけが新しくなり、コミットに入る変更はない。
- 今の構成では、アプリもサーバーも同じ PC の中で動く。LAN に出すときに考えることが、パスワードの決まり（B5）・ログインの守りの1点（B6）・同意の扱い（B15）と、たまってきた。
- 配布用のビルドの対象には、自作のモジュールを1つずつ書いている。main.js から読むモジュールを足すときは、ここにも足す。
