## 気づいたこと

- 測る前は、ハラスメントの話がキーワードに当たる場合（「上司に『自殺しろ』って言われた」など）を考えていなかった。
  - 最初に決めた形のままだと、判定が「危機ではない（ハラスメントはある）」と答えた回は、何も記録されない。
  - キーワードに当たらない軽い言い方は、ハラスメントとして記録される。そのため、重い言い方のほうが、記録から消えることになる。
  - ハラスメントの文を足して測り、結果を見せてから、ユーザーに決めてもらった。
- 判定の答えの読み方は、読めない答えを「危機ではない」として返していた。返事に進む回では、キーワードの安全網が別にあるのでよい。しかし、キーワードの回の記録では、安全側と逆になる。そこで、読めたかどうかも返すようにした。
